## Descrição

API REST para gerenciamento de produtos disponíveis na plataforma. Utilizada pelo Order Service para consultar preço e disponibilidade de produtos no momento da criação de pedidos.

---

## Endpoints

| Método | Rota | Descrição |
|--------|------|-----------|
| `GET` | `/products/{id}` | Retorna detalhes e preço de um produto |
| `GET` | `/products` | Lista produtos disponíveis |
